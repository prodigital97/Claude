Share from Instagram → Wanderlist

iPhones only let Shortcuts (not websites) appear in the Share sheet. Set this up once and you'll get a one-tap Share → Wanderlist from Instagram.

  1. Open the Shortcuts app → tap + to create a new shortcut.
  2. Tap the ⓘ / settings icon → turn on Show in Share Sheet. Under Share Sheet Types keep URLs (and Safari web pages) on.
  3. Add the action Open URLs (search "Open URLs").
  4. In the URL box, paste the line below, then place your cursor right after url= and tap the Shortcut Input variable to insert it:
https://prodigital97.github.io/Claude/wanderlist/index.html?autosave=1&url=
  1. Name it Wanderlist (and pick the app icon if you like) → Done.
  2. In Instagram: open a post → Share (paper-plane) → Share to… → scroll to Wanderlist. It saves automatically. 🎉

Tip: remove autosave=1& from the link if you'd rather review & edit each save (category, notes) before it's added.
